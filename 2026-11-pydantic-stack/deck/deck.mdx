### Step 2 - Code execution

# Code mode

<div style={{ display: 'grid', gridTemplateColumns: '1.3fr 1fr', gap: '2rem', alignItems: 'start' }}>

<div>

- aka "Programmatic tool calling", CodeAct, and RLM (Recursive Language Models)
- The model writes Python (or JS); the Python calls tools
- Tool composition, branching, looping - all happen in **code**, not round-trips
- Intermediate state stays in the runtime, not in the context window
- The agent only ever sees **two** tools: `run_code` and `find_tools`
- "1000 tools in 1000 tokens" is the promise
- even better: "1000 tool calls with 1 LLM call"

</div>

### Step 2 - Code execution

# Monty: hello world

A minimal Python interpreter, written in Rust, for code written by AI. No filesystem, env or network unless you grant it.

<div className="medium-code">

```py
from pydantic_monty import Monty

def get_who(greeting: str) -> str:
    return 'World' if greeting == 'Hello' else 'everyone'

code = """
greeting = 'Hi'
who = get_who(greeting)
f'{greeting} {who}'
"""
with Monty() as pool, pool.checkout() as session:
    output = session.feed_run(code, external_lookup={'get_who': get_who})
    print('output:', output)
    #> output: Hi everyone
```

</div>

### Step 2 - Code execution

# Code mode with Monty

One `run_code` tool - your tools become Python functions inside the sandbox.

<div className="medium-code">

```py
from pydantic_ai import Agent
from pydantic_ai_harness import CodeMode

agent = Agent(
    "gateway/anthropic:claude-sonnet-5",
    capabilities=[CodeMode()],
)

@agent.tool_plain
def get_weather(city: str) -> dict:
    """Get current weather for a city."""
    return {'city': city, 'temp_f': 72, 'condition': 'sunny'}

result = agent.run_sync("What's the weather in New York and London, in Celsius?")
print(result.output)
```
