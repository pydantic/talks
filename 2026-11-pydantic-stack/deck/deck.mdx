### Step 2 - Pydantic AI

# The harness

<Row align="flex-start" gap="1.8rem">
<Col flex="1 1 58%" className="medium-code">

```py
from pydantic_ai import Agent
from pydantic_ai.capabilities import LocalWorkspace
from pydantic_ai_harness.coder import Coder

agent = Agent(
    'anthropic:claude-opus-5-5',
    capabilities=[LocalWorkspace('.'), Coder()],
)
result = agent.run_sync(
    'Find out why tests/test_parser.py fails '
    'and fix the bug it caught.'
)
print(result.output)
```

</Col>
<Col flex="1 1 42%">

- **Capabilities** are the harness: reusable behaviour you add to any agent
- **`Coder`** is a coding agent in one line: file tools, a shell, sub-agents and `AGENTS.md` context
- **The workspace** is where it works: this machine, or a cloud sandbox
- Take it apart: `FileSystem`, `Shell` and `SubAgents` are capabilities too

</Col>

### Step 2 - Pydantic AI

# Decision models

<Row align="flex-start" gap="1.8rem">
<Col flex="1 1 58%" className="medium-code">

```py
class Outcome(UseEnumMemberDocstrings, StrEnum):
    accept = 'accept'
    """Outside every mapped flood zone..."""
    refer = 'refer'
    """In the 1% zone, 2 m or more above the water..."""
    decline = 'decline'
    """In the regulatory floodway..."""

class Decision(BaseModel):
    """Decide whether to offer buildings insurance."""
    outcome: Outcome
    flood_excess: bool

model = FallbackModel(
    'typesafe:jev-latest', 'anthropic:claude-sonnet-5',
    fallback_on=[ModelAPIError, unsure],
)
agent = Agent(model, output_type=Decision)
```

</Col>
<Col flex="1 1 42%">

- A **classifier**, not a writer: each field of the output type is one typed question
- Every answer has a **confidence**
- Fast and cheap enough to ask **on every item in a loop**
- The answers it is unsure of **fall back** to a language model
- Same `Agent`, different model string

</Col>
</Row>

import logfire
from pydantic_ai import Agent
from pydantic_ai_harness import CodeMode

agent = Agent(
    "gateway/anthropic:claude-sonnet-5",
    capabilities=[CodeMode(monty_sandbox=logfire.agent_sandboxes)],
)

@agent.tool_plain
def get_weather(city: str) -> dict:
    """Get current weather for a city."""
    return {'city': city, 'temp_f': 72, 'condition': 'sunny'}

result = agent.run_sync(
    "What's the weather in New York, London and Tokyo, in Celsius?"
